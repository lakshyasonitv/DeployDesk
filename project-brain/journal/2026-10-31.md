### Organisations (`/ops/organisations`)

The screen is read-only and ops-only: no controls, so no dead buttons and no tenancy risk,
and names and money are allowed under the owner's rule. What was left to check was whether
its numbers are true. Three figures were right on today's data only by coincidence:

- **"Billed as client" / "Paid as supplier" summed every engagement ever.** Today there are
  no ended engagements (all 21 are active, onboarding or ending), so the figure happened to
  be right. The first ended engagement would have kept counting. Both now sum only
  `onboarding / active / ending`, and the headers say **"Billed / mo"** and **"Paid / mo"**,

- **"Declared groups" = grouped orgs ÷ 2** assumed every group has exactly two members.
  It now counts distinct group names, and the subtitle lists all of them, not just the
  first.
- **"Block pairs" = orgs with any block ÷ 2** assumed each blocked org has exactly one
  block. It is now `Σ blockedWith ÷ 2`, which is exact, because the read model lists each
  pair on both sides. Both counts would have shown "1.5" the day the seed's one-of-each
  stopped being true.
- "Bench" counts every bench row including drafts. The vendor portal counts the same way,
  so this was left consistent rather than changed.

### Header overlap at narrow widths (`src/lib/ui/Shell.tsx`)

The demo switcher was `flex:none`, so it never shrank. The breadcrumb box had `min-width:0`,
so it shrank underneath its never-truncating screen name, which then overprinted the
switcher. **The first fix (`min-width:min-content`) did not work:** a `nowrap` span's

became two separate top-bar items. The tag uses shrink weight 10, so it gives way first.
