# Journal format

One file per day: `YYYY-MM-DD.md`. Multiple sessions in a day = multiple `## Session N` blocks in the same file. This file is a reference — do not delete it.

```markdown
# YYYY-MM-DD

## Session 1 — <short title>

### What was done
<!-- outcomes, not play-by-play -->

### Problems hit & how fixed
<!-- INCLUDING failed approaches and why they failed — most valuable section -->

### Files touched
<!-- paths only -->

### Next time start here
<!-- exact next action -->
```
