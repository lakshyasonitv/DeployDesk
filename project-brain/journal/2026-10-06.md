- Wrote the **seed in full** across seven modules, including the two-sided broker threads

  `sensitive_columns` tripwire registry.
- Wrote the **client and vendor read models**.

### Problems hit & how fixed

- **The documented scorer does not reproduce the design's rankings.** Applying the
  `docs/MATCHING.md` weights (30/22/16/14/10/8) to the prototype's own component arrays
  reproduces its `match` value only in Pool C; in pools A, B and D the order changes.
  Divergence is largest where freshness or vendor reliability penalise a candidate —
  TV-4488 computes 81 against a fixture 88. `docs/SEED-DATA.md` explicitly asked for this
  to be investigated rather than papered over. Concluded the fixture's scores and its bars
  were authored independently, for visual effect. **Recorded as ADR-011** and decided to
  compute the score from the components, because the matching workspace shows the bars next
  to the total and a total that does not follow from the bars cannot be defended to a
  broker. The hero shortlist order is unaffected — it is a `manual_rank`.

- **Fixture dates are pinned to 22-24 Aug 2026; today is 6 Oct.** Seeding them as absolute
  timestamps would render every profile unconfirmed-40d and every requirement breached.
  Wrote `fixtureDateToOffset()` to preserve each date's distance from the fixture reference
  and re-anchor the whole picture to `SEED_NOW`.

- **Bash heredocs kept failing** on the larger TypeScript files (`unexpected EOF`).
  Switched to the Write tool for code files; heredocs are still fine for short appends.

- **`git push` was refused** by the permission classifier with "Remote Repoint". Did not
  work around it. The remote is added, the repo is empty and reachable. Needs approval.

- **The publishable key cannot create tables.** The user supplied the project URL and
  `sb_publishable_…` key; neither is a Postgres credential. Asked for the two connection
  strings instead. The Supabase MCP connector is installed but still unauthorised, so
  `/mcp` remains an alternative route.

- Wrote and then removed two pieces of my own sloppiness: a `require()` call inside an ESM
  schema module, and `await import("drizzle-orm")` inside a loop. Both replaced with
  top-level imports.
